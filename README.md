# E-Commerce Sales Analysis Dashboard

## Project Overview

An interactive E-Commerce Sales Analysis Dashboard developed using Microsoft Excel to analyze sales, profit, quantity, orders, and profit margin.

## Dashboard Preview

![E-Commerce Sales Dashboard](dashboard.png)

## Key KPIs

- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity: 37,873
- Total Orders: 9,994
- Profit Margin: 12.47%

## Features

- Sales and Profit Analysis
- Category-wise Profit Analysis
- Category-wise Sales Share
- Sales by State
- Top 5 Subcategories by Sales
- Year-wise filtering
- Region-wise filtering
- Segment-wise filtering
- Interactive Excel slicers

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Functions
- Data Analysis
- Dashboard Design
